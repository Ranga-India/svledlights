# About the project

A static website built for svledlights.com. SV LED LIGHTS is a bulb manufacturing company that distributes and sells bulbs wholesale to distributors and suppliers in Bengaluru, India.

The company was established in 2020 and has served hundreds of clients since then.

The site now uses brochure-based product photos and a cleaner catalog layout.

Main product range:

* LED Bulbs - 9W, 12W, 15W, 20W, 30W, 40W, 50W
* LED Batten Light
* Street Bulbs - 20W, 30W, 50W

Company is ISO certified and CPRI approved
